# Module Review

本文是 L2 模块审查证据表。常规审查先读 [review-log.md](review-log.md)；只有需要逐模块核对实现、测试证据和风险时再读本文。

架构合同见 [architecture.md](architecture.md)，硬规则见 [engineering-rules.md](engineering-rules.md)，历史流水见 [review-history/2026-06-19.md](review-history/2026-06-19.md)。

2026-06-21 新增 [工作流与模块交互专项审查](workflow-module-interaction-review-2026-06-21.md)。下表中的自动化证据仍然有效，但“模块内测试通过”不再等同于“跨模块合同通过”；受持久化、并发、TTS 调度和视觉优先级影响的模块已调整为“部分通过”。

## 结论等级

- 通过：有实现和自动化测试证据支持。
- 部分通过：主路径有证据，但仍有边界、工具或真实软件验证缺口。
- 待处理：与文档要求不符或证据不足。

审查口径：结论按当前状态 / 当前承诺判断；已明确列入后续重点的增强项不反向判定为当前未完成，但必须保留为风险或路线图。

## 2026-06-25 状态补记

- PSD 图层模板入口不再只依赖当前选中角色；任一角色存在可读取 PSD source 时即可启用，并回退指向第一个可配置 PSD 角色。
- PSD AI 匹配当前只让 AI 选择 `brow/eye/mouth/leftHand/rightHand` 五类固定词汇。固定词汇表位于 system prompt 的约束和 JSON 返回形态之后，user prompt 只含文本行或 rows JSON，不发送 layer id、坐标或 PSD 图层位置；AI 空值或非法候选不再抛异常，而是由本地当前 PSD 图层结构解析默认可见 renderable 层。只有选中/默认层和受控层都能在当前 PSD 中可靠解析出 layer id 的槽位才进入 selection override，`ControlledLayerIds` 优先于重复叶子名，避免上一个角色模板或同名“手掌/袖口”误清掉下一个角色/姿势的默认手。
- 角色内心/角色动作行以 `SourceRoleCharacterId/SourceRole` 解析角色视觉，导出时拥有角色图或角色 PSD rendered PNG，并且角色内心、角色动作、旁白/场效音频分轨进入 `EditingTimeline` 八轨。
- 参考音频试听只走 ComfyUI `voice-preview` 音频接口；Draft Agent 不通过该接口读取 `.txt` / `.reference.txt`，也不下载 ComfyUI models 目录文件。参考文本持久优先级交给 `tts_audio_suite` 的 `.reference.txt` > `.txt`，App 只提交用户手填临时 `reference_text`。
- 角色管理中台词细分按钮当前显示“台词使用角色参考音”。
