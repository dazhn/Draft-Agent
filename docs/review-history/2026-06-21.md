## 变更记录

- TTS 生成项目目录前置：主界面“语音合成”按钮在当前没有 workspace project manifest 时，会先调用现有文件夹选择器要求用户选择或新建工作台项目目录；选择后打开/保存当前项目，再继续执行语音合成。取消选择时设置“语音合成已取消：未选择项目保存目录”和“未提交：请先选择项目保存目录”，不触发 ComfyUI。
- 命令层硬阻断无项目目录的语音生成：`RunTtsSynthesisOperationAsync` 在设置运行状态前统一调用项目目录预检；无项目时直接返回并提示“语音合成前请先点击‘打开’选择或新建项目文件夹，保存项目后再开始合成”。因此一键语音合成、继续 TTS 队列、全量 ComfyUI 提交、角色目标重生成和单行重生成都不能绕过项目目录要求。
- TTS 运行中取消入口补齐：顶部“语音合成”按钮由 `TtsSynthesisActionText` 驱动，空闲时显示“语音合成”，运行中切换为“取消合成”；再次点击会执行 `CancelTtsSynthesisCommand` 并触发当前 TTS cancellation token。`TtsSynthesisQueueService` 对 `OperationCanceledException` 直接继续抛出，不再把任务写成 Failed；App 的 TTS 命令对取消异常继续上抛到统一运行包装，最终显示“语音合成已取消”并恢复工作台拖拽状态。
- 声音同步元数据不再触发已完成 TTS 重置：打开/保存项目后，参考音频同步可能给 TTS 任务补 `voiceSourceAssetId` 和 `voiceSyncedPath`。`WorkbenchTaskPreservationPolicy` 现在把这两个字段视为非渲染同步元数据：匹配任务时忽略它们，但会把最新值合并回已保留任务；只要文本、情绪、参考音频引用和参考文本未变，就保留 `Completed` 和 `ResultAssetId`，避免用户刚保存项目目录后所有已完成语音被误判为需要重合成。
- 角色管理语义纠偏：顶部原“绑定”按钮固定为“角色管理”，不再随弹窗打开变成关闭动作；弹窗标题改为“角色管理”，说明改为“管理角色素材、台词归属和旁白语音”。弹窗只展示“角色素材”和“旁白语音”，场景素材卡从弹窗移除，避免角色管理页同时承担场景素材职责。
- 角色管理弹窗按钮区调整：弹窗右上角按钮顺序为“增加角色 / 保存 / 关闭”。“保存”复用 `SaveWorkbenchEditsCommand`；“增加角色”使用 `AddManagedCharacterCommand` 创建唯一默认名 `新角色 N`，刷新 Project、角色名选项和角色素材卡，并自动选中新角色卡进入名称编辑态；“关闭”只关闭弹窗。
- 角色卡名称编辑改为显式保存：角色名默认只读，点击名称或右上角“重命名”按钮才进入编辑态；编辑态按钮文案变为“保存”，只有点击保存或按回车才提交改名，失焦不会保存。保存时移除所有空白字符，例如 `林 安` 会保存为 `林安`；空名和重名继续阻断并提示。

## 当前约束

- TTS/ComfyUI 生成链路必须先有项目目录；没有项目目录时只能继续编辑，不能提交语音合成或重生成。
- TTS 取消属于正常用户操作，不应标记任务 Failed，也不应显示“合成失败”。
- `voiceSourceAssetId` / `voiceSyncedPath` 只代表参考音频项目化同步位置，不代表语音内容变化；不得单独导致 completed TTS 失效。
- 场景图片只能绑定普通 PNG/JPG/WebP/BMP；PSD/PSB 仍仅支持人物 PSD 图层流程。
- 场景图片入口属于工作台场景行；角色素材和旁白语音入口属于角色管理弹窗。
- 角色删除不能静默把台词转旁白；如后续实现删除角色，必须先设计引用处理策略，例如合并、替换或只允许删除未引用角色。
- 角色改成已有名称不执行普通重命名；必须先确认合并，确认后源角色所有引用统一归入目标角色，源角色卡片从角色管理中移除。
